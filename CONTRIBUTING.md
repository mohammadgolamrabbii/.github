# 🤝 Contributing to Open Typography Archives

Welcome to the **World's Largest Multilingual Open Typography Ecosystem** maintained by [Mohammad Golamrabbii](https://linktr.ee/golamrabbii). We welcome font designers, archivists, type foundries, and developers worldwide to contribute.

---

## 🌟 How You Can Contribute

1. **Submit New Typefaces:**
   * Open a [Font Request Issue](https://github.com/mohammadgolamrabbii/.github/issues/new?template=01_font_request.yml).
   * Ensure the font is released under an approved open-source license:
     * **SIL Open Font License 1.1 (OFL)**
     * **Apache 2.0**
     * **MIT / BSD**
     * **Creative Commons Zero (CC0) / Public Domain**

2. **Report Rendering Glitches & Broken Glyphs:**
   * If a font has missing conjuncts, overlapping ligatures, or bad hinting, open a [Bug Report](https://github.com/mohammadgolamrabbii/.github/issues/new?template=02_bug_report.yml).

3. **Improve Tooling & Web Previewer:**
   * Help improve our interactive web font previewer at [typography](https://github.com/mohammadgolamrabbii/typography).
   * Submit pull requests to our CLI package manager [get-openfonts](https://github.com/mohammadgolamrabbii/get-openfonts).

4. **Participate in Community Discussions:**
   * Join discussions, share specimens, and help fellow designers identify fonts in [GitHub Discussions](https://github.com/mohammadgolamrabbii/Awesome-Open-Typography/discussions).

---

## 📜 Curation Standard
We strictly preserve cultural authenticity while adhering to 100% open-source licensing. Commercial or pirated typefaces are immediately declined and removed.
